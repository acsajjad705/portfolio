# Portfolio Website

A responsive, accessible, and interactive portfolio website built with **HTML**, **CSS**, and **JavaScript**.  
Deployed via **GitHub Pages** for easy review and feedback.

---

## ✨ Features

- **Semantic HTML structure** with clear sections (`header`, `nav`, `main`, `footer`).
- **Accessibility support**: alt tags, skip link, ARIA roles, focus styles, and aria-live error messages.
- **Global CSS styling**: consistent theme, typography, and component design.
- **Responsive design**: media queries for mobile, tablet, and desktop layouts.
- **JavaScript interactivity**:
  - Dark/light theme toggle (persisted with localStorage).
  - Mobile navigation menu toggle.
  - Accessible form validation with error messages.
